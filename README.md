# beyond-linearity-splines-and-gams-with-scikit-learn
Chapter 7 of An Introduction to Statistical Learning on the book's own Wage data. Fit wage against age with polynomials, step functions, regression splines, a penalized smoothing spline and a local smoother, see why a degree-four polynomial explodes past the data, then assemble a generalized additive model and read its partial effects.
